### Acerca de mí 🚀

Desarrollador especializado en **infraestructura, IoT y sistemas de bajo nivel**. Mi filosofía de arquitectura es pragmática y estricta: construyo sistemas críticos 24/7 en tiempo real, garantizando robustez, latencia prácticamente nula y **cero dependencias de terceros** (enfoque *Local-First*). 

Actualmente me desempeño como Arquitecto de Software y DevOps en la Planta Potabilizadora Echeverría (Paraná), desarrollando sistemas predictivos, telemetría y cálculos de dosificación automatizados a partir de datos de PLCs.


### Proyectos Destacados ⚙️
*   **V-NYCH:** Ecosistema *Local-First* autoalojado de productividad (notas, calendario, tareas). Arquitectura en Rust, Go y PostgreSQL contenerizada en Docker.
*   **CapiOS:** Distribución Linux custom basada en Debian, optimizada a nivel kernel para Raspberry Pi 5.
*   **Atlas (En desarrollo):** Ecosistema IA autónomo para domótica integrado con Home Assistant.
*   **Smart Miata:** Colaborador en el desarrollo de un OS modular open-source para vehículos (robótica, sensores y telemetría).
